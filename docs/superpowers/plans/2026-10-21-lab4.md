# План лабораторной работы №4

Цель: автономный React-клиент системы совместного редактирования документов на основе модели из ветки 23. Поля: id, title, content, status, createdAt, updatedAt. Данные сохраняются только в браузере. Ветка сдачи: 24.

1. Создать frontend на Vite, React и React Router. Серверные файлы лабораторной №3 сохранить.
2. Проверить тестами восстановление массива из localStorage: отсутствующие и повреждённые данные дают два примера; сохранённый пустой список остаётся пустым. Реализовать проверку структуры и безопасные операции хранения.
3. Реализовать useLocalStorage и DocumentsContext: загрузка через useEffect с [] и таймером 1000 мс, запись после загрузки, CRUD через функциональное обновление состояния, изменение document.title.
4. Реализовать список с поиском, фильтром статуса, сортировкой и статистикой; контролируемую форму создания/редактирования; автосохранение черновика через 500 мс с очисткой таймера.
5. Проверить сборку и браузерные сценарии CRUD, фильтрации, перезагрузки, восстановления черновика, ошибок хранения и пустого списка. Обновить инструкцию запуска и только текст DOCX, сохранив исходное оформление и изображения.

Особое внимание: StrictMode не должен затирать хранилище; повреждённый JSON и запрет записи не должны ломать интерфейс; удалённый документ должен давать понятную страницу; пустая форма не должна создавать документ; сортировка не должна изменять массив состояния.

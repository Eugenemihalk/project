# Приложение для совместного редактирования документов

Лабораторная №5: React + Express + PostgreSQL + JWT.

## Структура

- `client/` — React, Vite, формы входа/регистрации и интерфейс документов.
- `server/` — Express API, модели Sequelize, миграции и настройки PostgreSQL.
- `docs/` — материалы предыдущих лабораторных.

## Настройка и запуск

В `server/.env` задайте `DATABASE_URL`, `JWT_SECRET` (минимум 32 символа), `PORT=7000` и `CLIENT_ORIGIN=http://localhost:5173`. Существующий локальный `.env` перенесён вместе с сервером.
В `client/.env` задайте `VITE_API_URL=http://localhost:7000` (без `/api`). Примеры находятся в `.env.example` каждой части.

Сервер, в первом терминале:

```bash
cd server
npm install
npm run db:migrate
npm run dev
```

Клиент, во втором терминале:

```bash
cd client
npm install
npm run dev
```

Откройте http://localhost:5173 и зарегистрируйтесь. После регистрации выполняется автоматический вход. Для удаления документов назначьте аккаунту роль администратора:

```bash
cd server
npm run set-admin -- email@example.com
```


## Возможности и проверка

GET/POST/PUT/DELETE работают через JWT. Добавление, изменение и удаление оптимистичные, при ошибке выполняется откат. Загрузка показывает индикатор, ошибка — сообщение с кнопкой «Повторить». Дополнительное улучшение — отмена загрузки через AbortController при размонтировании. Поиск, фильтрация и сортировка выполняются на клиенте; документы загружаются с API без HTTP-кэша. Текст редактора не сохраняется в браузере: несохранённые изменения теряются при перезагрузке.

Для ручной проверки: войдите, создайте, измените и удалите документ под администратором. Остановите сервер и проверьте сообщение об ошибке и откат. Запустите сервер и нажмите «Повторить».

В папке `client` команда `npm run build` собирает клиент в `client/dist/`. `npm test` запускает существующие тесты локального хранилища; они не заменяют проверку API с PostgreSQL.

Это минимальная работа с общими документами через REST. Передача правок в реальном времени не реализована.
Для сдачи используйте ветку `25`. В отчёте `отчет5_документы.docx` замените изображения своими и экспортируйте документ в PDF.
